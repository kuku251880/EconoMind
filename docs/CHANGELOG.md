# 更新记录

## 第一阶段 · 项目准备

- 初始化 Git 仓库，初始分支为 `main`。
- 建立前端、后端和文档目录，确认 MVP 架构。
- 建立项目说明、协作规范、路线图、架构说明、学习记录和更新记录。

## 第二阶段 · 后端基础

- 建立 Python 虚拟环境和运行、测试依赖清单。
- 添加 GDP 和 CPI 元数据查询接口、输入校验和自动化测试，验证 Uvicorn 本机 HTTP 响应。
- 添加后端启动与测试说明，以及虚拟环境、缓存和环境文件的 Git 忽略规则。

## 第三阶段 · 数据库与数据分析

- 接入 PostgreSQL 和 SQLAlchemy，添加用户、数据集、指标和观测值的初始表结构。
- 添加 CSV 校验、事务导入、合成样例与季度时间序列查询接口。
- 添加同比、环比计算和测试，以及数据库配置与查询说明。

## 第四阶段 · 前端基础

- 新建 React、TypeScript、Vite 和 Tailwind CSS 前端。
- 增加按数据集、指标和日期查询的仪表盘，支持 ECharts 趋势图、最新指标摘要和季度明细。
- 添加加载、空结果、查询错误和日期范围校验反馈，记录前端启动与构建方式。
