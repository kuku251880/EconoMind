# 学习记录

## 第一阶段 · 项目准备

- PowerShell 的命令搜索路径影响工具能否直接调用。已验证 Python、Git、Node.js 和 npm 可用，`py` 启动及从项目目录调用 VS Code CLI 曾出现异常。
- `git init` 建立本地仓库，首次提交才产生提交历史。Git 跟踪文件，空目录不会出现在状态里。
- 前端负责交互和展示，后端通过 HTTP API 管理权限和业务规则，数据库负责持久化。事务可保证批量导入整体成功或整体回滚。

## 第二阶段 · 后端基础

- `venv` 为项目隔离依赖，`python -m pip` 使用指定解释器安装包。
- Uvicorn 接收 HTTP 请求并交给 FastAPI。接口先校验 URL 中的指标代码，再读取内置名称，最后将 Pydantic 响应模型序列化为 JSON。
- `200` 表示查询成功，`422` 表示指标代码未通过输入校验。Pytest 通过 ASGI 测试客户端验证接口行为，本机 HTTP 检查额外验证服务启动和网络请求。
