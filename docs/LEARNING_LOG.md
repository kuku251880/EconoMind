# 学习记录

## 第一阶段 · 项目准备

- PowerShell 的命令搜索路径影响工具能否直接调用。已验证 Python、Git、Node.js 和 npm 可用，`py` 启动及从项目目录调用 VS Code CLI 曾出现异常。
- `git init` 建立本地仓库，首次提交才产生提交历史。Git 跟踪文件，空目录不会出现在状态里。
- 前端负责交互和展示，后端通过 HTTP API 管理权限和业务规则，数据库负责持久化。事务可保证批量导入整体成功或整体回滚。

## 第二阶段 · 后端基础

- `venv` 为项目隔离依赖，`python -m pip` 使用指定解释器安装包。
- Uvicorn 接收 HTTP 请求并交给 FastAPI。接口先校验 URL 中的指标代码，再读取内置名称，最后将 Pydantic 响应模型序列化为 JSON。
- `200` 表示查询成功，`422` 表示指标代码未通过输入校验。Pytest 通过 ASGI 测试客户端验证接口行为，本机 HTTP 检查额外验证服务启动和网络请求。

## 第三阶段 · 数据库与数据分析

- 用 SQLAlchemy 表定义映射 PostgreSQL 的主键、外键和精确数值类型。主键界定唯一的观测值，外键约束引用关系。
- CSV 文本先经过解析与校验，再进入数据库事务。遇到无效数据时，用户可根据行号定位问题。
- 同比和环比按实际季度寻找基期，适用于中间缺少观测值的序列。`Decimal` 保留小数精度，基期缺失或为零时返回空值。

## 第四阶段 · 前端基础

- HTML 表单定义标签和输入校验，React 保存筛选条件和请求状态。TypeScript 类型描述了后端返回的 JSON 结构。
- Tailwind CSS 负责页面样式和响应式布局。ECharts 使用观测值绘图，缺少的中间季度保留为空。表格直接显示 API 返回的精确小数字符串。
- 浏览器向同源的 `/api` 发起请求，Vite 在开发时将其代理给 FastAPI。切换筛选时取消旧请求，避免旧结果覆盖新查询。

## 第五阶段 · MVP 闭环

- 密码哈希用于验证凭据。会话令牌用于识别后续请求。将会话存入数据库允许过期和主动撤销。
- 浏览器上传使用 multipart 表单。后端先检查登录权限，再复用已有 CSV 校验和事务。数据集写入上传者，查询按当前账号过滤。
- 用两个浏览器账号和实际 PostgreSQL 验证了完整用户流程，并检查只知道数据集编号时也无法访问他人的私有数据。

## 第六阶段 · AI 研究助手

- 函数调用由模型发出请求，业务代码负责执行并验证权限。把证据返回给模型后，再让模型组织答案。
- 结构化输出让程序能分开处理段落与引用。真实来源由数据库和后端生成，浏览器可跳转到原始观测值。
- 在缺少模型密钥时，可以用模拟 HTTP 响应验证 SDK 的两轮调用、参数边界和界面行为。最终模型表现需要用真实请求验收。

## 第七阶段 · 季度预测基线

- 预测基线使用上一季度的实际值。逐期回测时，预测只使用该季度之前已有的数据，实际值用于事后计算误差。
- MAE 平均每期偏差的绝对值。RMSE 先平方再平均、开方，对较大的误差更敏感。两者都保留原始单位。
- 缺少上一季度时跳过该点，真实观测值为零时仍可用于预测。本次样例的有效点数量有限，可核对计算流程。

- 线性趋势模型用最小二乘法选择直线，使四期训练观测的平方残差之和最小。每次滚动向前时重新拟合。
- 比较模型时应固定预测目标。用只满足基线条件的季度计算基线误差，会让两个误差指标对应不同的样本。
- 数据量达到四个连续季度只能生成一次下一季度估计，需要第五个季度的实际值才能为这次估计计算回测误差。

## 本地数据中心

每季发布表的「当季绝对额」按现价计量。将这些金额逐期相除得到名义变化；解读国家统计局公布的实际同比或季调环比，需要使用相应口径的序列。数据中心保留各季首次发布的链接和日期，便于复核。

信息传输、软件和信息技术服务业的增加值已计入第三产业。计算行业占比时选用同季度同张表的 GDP。不同季度采用各自初次公布的数据，跨年比较可能跨越核算修订；三次产业之和也可能因取整与公布的 GDP 略有差异。
